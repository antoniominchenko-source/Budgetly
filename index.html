Режим без входа

Žádné další přihlašování přes Google. Malý skript ve tvé tabulce se o přístup postará sám. Nastavení trvá asi 3 minuty a stačí ho udělat jednou.
Больше никакого входа через Google. Небольшой скрипт в твоей таблице сам занимается доступом. Настройка занимает около 3 минут и делается один раз.
  1. Otevři svou tabulku v Google Sheets → Rozšíření → Apps Script. Smaž vše, co tam je.
  2. a vlož ho do editoru → Uložit (ikona diskety).
  3. Vlevo u Služby (+) vyber Google Sheets API → Přidat.
  4. Nahoře vyber funkci authorize → Spustit → povol přístup (Upřesnit → Přejít na projekt → Povolit).
  5. Nahoře Nasadit → Nové nasazení → typ Webová aplikace. „Spustit jako“: Já, „Kdo má přístup“: Kdokoli → Nasadit. (Když už nasazení existuje: Spravovat nasazení → tužka → Nová verze.)
  6. Zkopíruj URL webové aplikace a vlož ho sem:
  1. Открой свою таблицу в Google Sheets → Расширения → Apps Script. Удали всё, что там есть.
  2. и вставь в редактор → Сохранить (иконка дискеты).
  3. Слева у Сервисы (+) выбери Google Sheets API → Добавить.
  4. Сверху выбери функцию authorize → Выполнить → разреши доступ (Дополнительно → Перейти в проект → Разрешить).
  5. Сверху Развернуть → Новое развёртывание → тип Веб-приложение. «Запуск от имени»: Я, «У кого есть доступ»: Все → Развернуть. (Если развёртывание уже есть: Управление развёртываниями → карандаш → Новая версия.)
